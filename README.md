# InviteShield

Lightweight Discord moderation bot that automatically removes Discord invite links.

## Features

- Anti Discord Invite
- Auto Delete Message
- Moderator Logs
- Role Whitelist
- Channel Whitelist
- Administrator Bypass

## Installation

```bash
pip install -r requirements.txt
```

Create `.env`:

```env
TOKEN=YOUR_BOT_TOKEN
```

Run:

```bash
python bot.py
```
